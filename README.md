# 📄 DocFormat AI

DocFormat AI is a Streamlit-based AI document auditing application that analyzes PDF and DOCX files for formatting consistency, document structure, missing sections, and user-provided academic requirements.

## 🚀 Features

- PDF and DOCX upload
- Font family detection
- Font-size detection
- Alignment detection
- Basic line-spacing detection
- Page count detection
- Page-number detection
- Missing section detection
- Assignment benchmark
- Project Report benchmark
- General / Business Report benchmark
- Teacher / Institute custom requirements
- AI-powered recommendations
- Structured JSON analysis
- Suggestion/recommendation disclaimer tone

## 🛠️ Technology Stack

- Python
- Streamlit
- Groq API
- Llama 3.3 70B Versatile
- python-docx
- pdfplumber
- pypdf
